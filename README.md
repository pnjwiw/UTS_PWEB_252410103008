## Deskripsi Website

SISCO CUP 2026 merupakan website pengelolaan turnamen esports berbasis Laravel yang menerapkan konsep MVC (Model View Controller), Blade Template, Request Handling, dan Array Rendering.

## Fitur

- Login Organizer
- Dashboard Turnamen
- Profile Organizer
- Pengelolaan Tim Esports
- Data Username dari Login ke Dashboard dan Profile
- Menampilkan Data Tim Menggunakan @foreach

## Teknologi

- Laravel
- PHP
- Bootstrap 5
- Blade Template Engine
